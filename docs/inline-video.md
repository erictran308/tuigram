# Inline-воспроизведение кружков (video notes): статус и известный баг

Рабочие заметки нашего форка. Продолжать можно с любой машины: весь код в
`main`, здесь — контекст, который не виден из коммитов.

## Симптом (не закрыт)

При воспроизведении кружка по Space (inline, в чате) кадр **обрезан снизу
прямой линией**, левый верх на месте. При этом:

- масштабирование medium (2x) работает — пузырь расширяется как надо;
- после окончания воспроизведения превью (thumbnail) — идеальный круг;
- полноэкранный плеер (Enter) работает всегда.

Вывод: ломается только путь kitty virtual placement для кадров
(`Inline::send_frame` + `InlineImage`), а не раскладка пузыря и не
thumbnail-путь ratatui-image.

## Следующие гипотезы, если на 506e44b всё ещё режет

1. kitty вписывает кадр в `c×r` с сохранением пропорций (contain). Если бокс
   слота не квадратный в пикселях (рассинхрон `images.font_size()` и
   реальной геометрии ячейки kitty), будут поля, но НЕ обрезка. Обрезка =
   плейсмент больше нарисованных ячеек: сравнить `slot.cols/rows` в
   `draw_photos` с тем, что реально пишет `InlineImage` (`skip`, клип по
   `area.height`).
2. Замерить фактический размер ячейки: `kitten @ ls` / query через
   `\x1b[16t` против того, что меряет ratatui-image.
3. Попробовать отдельный плейсмент: `a=p,U=1,i=…,c=…,r=…` после `a=t`
   (передача без отображения), как рекомендуют доки kitty.
4. Воспроизвести без Telegram: python-скрипт, пишущий в kitty те же escape
   (U+10EEEE + диакритики + `a=T,U=1,f=32,t=f,s=…,v=…,c=…,r=…` с base64
   путём к raw-кадру), гонять сценарии «статика», «рост бокса», «кадры
   подряд». Такой пробник уже подтвердил: статика и рост бокса с
   перерисовкой всего бокса работают корректно.

## Где код

- `src/video.rs` — `Inline` (плеер), `Inline::send_frame` (передача кадра),
  `InlineImage` (плейсхолдер-ячейки), `mask_circle` (круглая альфа-маска),
  `VideoView` (полноэкранный, рабочий эталон — там есть `c`/`r`).
- `src/ui/messages.rs` — `photo_cells` (маленький размер), `medium_cells`
  (большой, квадратный в пикселях), `draw_photos` (выставляет
  `player.placement`, рендерит `InlineImage`).
- `src/app.rs` — `toggle_inline_video` (Space), `zoom_inline_video` (z),
  `qwerty()` (раскладко-независимые клавиши).

## ВАЖНО: как НЕ тестировать

Нельзя запускать второй экземпляр tuigram на **копии** живой TDLib-базы
(`TG_DATA_DIR=/tmp/copy`): копия = та же сессия с тем же auth-ключом.
Telegram отвечает `406 AUTH_KEY_DUPLICATED` и **насовсем отзывает ключ** —
сессия умирает, нужен перелогин (уже словили 2026-11-24). Для живых тестов:
основной клиент + скриншоты, либо отдельный тестовый аккаунт Telegram.
